Day 5 - Array and ArrayList

Array

Arrays are fixed-size data structures that hold elements of the same type. They are declared using the following syntax:

dataType[] arrayName; // Declaration
dataType[] arrayName = new dataType[size]; // Initialization

Example:

int[] numbers = new int[5]; // An array of 5 integers

ArrayList

ArrayLists are dynamic data structures that can grow and shrink in size. They are part of the Java Collections Framework and provide more flexibility than arrays. They are declared using the following syntax:

ArrayList listName = new ArrayList<>(); // Declaration and Initialization

Example:

ArrayList names = new ArrayList<>();
names.add("Alice");
names.add("Bob");
names.add("Charlie");

Size of ArrayList

You can get the size of an ArrayList using the size() method:

int size = names.size(); // Returns the number of elements in the ArrayList

Example Code

Here is an example of how to use an ArrayList in Java:

import java.util.ArrayList;
public class SizeExample {
    public static void main(String[] args) {
        ArrayList names = new ArrayList<>();
        names.add("Alice");
        names.add("Bob");
        names.add("Charlie");
        System.out.println("Size of ArrayList: " + names.size());
    }
}
