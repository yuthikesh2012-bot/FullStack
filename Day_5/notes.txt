Array vs ArrayList(Difference)

1. Array fixed in size. ArrayList dynamic and
grow or shrink as needed.

2. Array [] operator to access elements.
ArrayList uses methods add(), remove() and
get().

3. Array supports data types and objects. Array
list supports only objects.
